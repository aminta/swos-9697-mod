## English

**SWOS 96/97 Mod 3.2.2: Download all**

- The patcher page has a **Download all** button: one zip with every patched file, already in the right folders (the
  executable in the game folder, the TEAM files in `DATA`). Extract it into the game folder (after backing it up).
  The SWOS++ version of the English executable, when you drop it, goes into a `SWOS++` folder of its own. Suggested by
  Marco.
- The game is the same as 3.2.1 (no file of the game changed). Updating from 3.2.1 is not needed.

## Italiano

**SWOS 96/97 Mod 3.2.2: Scarica tutto**

- La pagina del patcher ha un pulsante **Scarica tutto**: uno zip con tutti i file modificati, già nelle cartelle
  giuste (l'eseguibile nella cartella del gioco, i file TEAM in `DATA`). Estrailo nella cartella del gioco (dopo
  averne fatto una copia). La versione SWOS++ dell'eseguibile inglese, se la trascini, va in una cartella `SWOS++` a
  parte. Suggerito da Marco.
- Il gioco è identico alla 3.2.1 (nessun file del gioco cambia). Chi ha la 3.2.1 non deve aggiornare.

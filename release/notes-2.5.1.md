## English

**SWOS 96/97 Mod 2.5.1: incremental update**

The game content is the same as 2.5. What changes is the patcher.

- **Upgrade in place.** You no longer need the original files to install a new release. Drop the executable and `DATA\TEAM.020` of the game you already modified (any release from 1.0 to 2.5, original CD or GOG) and the patcher brings them to the latest version. Files that are already up to date are reported as such; with an up-to-date `TEAM.020` it still creates the new TEAM files a release may add.
- **How:** the page contains, for every earlier release, the differences between its files and the current ones, and recognises your file by its checksum before and after patching. A file it does not know (modified by hand or by another tool) is refused, not touched.
- Saves are never touched. As before, a new career is needed to see new leagues and teams.
- The patcher page is 1.4 MB (it was 0.5 MB) because it carries those upgrade differences.

Suggested by a user of the mod: thank you.

## Italiano

**SWOS 96/97 Mod 2.5.1: aggiornamento incrementale**

Il contenuto del gioco è quello della 2.5. Cambia il patcher.

- **Aggiornamento sul posto.** Non servono più i file originali per installare una nuova release. Trascina l'exe e `DATA\TEAM.020` del gioco che hai già modificato (una qualsiasi release dalla 1.0 alla 2.5, CD originale o GOG) e il patcher li porta all'ultima versione. I file già aggiornati vengono segnalati; con un `TEAM.020` aggiornato crea comunque i nuovi file TEAM che una release può aggiungere.
- **Come:** la pagina contiene, per ogni release precedente, le differenze fra i suoi file e quelli attuali, e riconosce il tuo file dal checksum prima e dopo la modifica. Un file che non conosce (modificato a mano o con altri strumenti) viene rifiutato, non toccato.
- I salvataggi non vengono mai toccati. Come prima, per vedere campionati e squadre nuovi serve una carriera nuova.
- La pagina del patcher pesa 1,4 MB (prima 0,5 MB) perché contiene queste differenze di aggiornamento.

Suggerito da un utente della mod: grazie.
